Token wire format

NONCE12 bytes · 96-bit
CIPHERTEXTN bytes · encrypted plaintext
GCM TAG16 bytes · 128-bit auth
Minimum valid token = 12 + 16 = 28 bytes (empty plaintext). The tag authenticates the ciphertext and the AAD.
