# JEE (Advanced) 2025 — Paper 1 · Solutions in TypeScript

Fully solved answer key and step-by-step solutions for **JEE (Advanced) 2025, Paper 1**
(Mathematics, Physics, Chemistry — 48 questions), written in TypeScript.

For every numerical / mathematical question the value is **computed in code** (not
hard-coded), so running the program both prints and verifies the answer. All answers
were cross-checked against the official Final Answer Key.

## Files
- `paper1-solutions.ts` — full step-by-step solutions (reasoning + live computation per question).
- `paper1-answer-key.ts` — compact answer key with one-line justifications + numeric verification block.

## Run
```bash
npx tsc --skipLibCheck --target es2020 --module commonjs paper1-solutions.ts
node paper1-solutions.js
```
